# Login

Diatur di js/config.js (bagian auth).
- mode 'off': tanpa login.
- mode 'local' (bawaan): DEMO, akun di perangkat pengguna.
- mode 'supabase': akun sungguhan. Isi supabaseUrl dan supabaseKey (anon key), ubah mode. Belum diuji dengan akun nyata.
- required true: wajib login sebelum latihan.
Lihat docs/KEAMANAN.md untuk batasan dan langkah menuju versi berbayar.
